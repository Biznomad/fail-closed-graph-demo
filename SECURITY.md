# Security policy

## Scope

This repository is an educational, local reproduction of a narrow persistence control. It is not a production service, security product, compliance control, or automatic retry engine.

## Reporting

Do not open a public issue containing secrets, personal data, customer data, or exploit details. Until a dedicated security contact is published, report only non-sensitive correctness problems through GitHub issues.

## Supported versions

Only the current default branch is maintained. No security support or response-time guarantee is offered.
